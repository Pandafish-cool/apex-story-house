# APEX 故事屋 🎉

一个从 2023 年出发的团队庆祝网页，收录 116 张团队照片，用互动抽签邀请大家讲述每张照片背后的故事。

## 使用

下载或克隆仓库，在浏览器中打开 `index.html` 即可使用。也可以运行：

```sh
python3 -m http.server 8013
```

然后访问 `http://localhost:8013`。

## 功能

- Cindy 与 Tun 双人主视觉，动态拉旗、气球、彩纸与掌声互动。
- 团队故事章节、全部照片分类、搜索和大图浏览。
- 116 张照片不重复随机抽取，可重开一轮。
- 大图投屏模式，可切换完整显示或裁切铺满。
- 每张照片可写故事，自动保存草稿，可导入/导出 JSON 备份。
- 可手动开启背景配乐，支持手机和减少动态偏好。

故事和抽签进度保存在当前浏览器，不会自动在多人或不同设备间同步。重要故事请导出备份。

## 内容与授权

大图直接使用未经缩小或重新压缩的原始 JPG。4 张原始文件只有约120像素，放大无法恢复细节；页面会提示并避免默认强制放大。

团队照片由项目所有者提供，仅供获授权的团队成员使用，不授予公开再分发许可。照片按主题编排，除已确认的成立年份与照片中可见活动年份外，不推测具体项目史。

背景配乐为本项目合成制作。标题字体为 ZCOOL KuaiLe，遵循 SIL Open Font License，参见 `assets/font-license.txt`。本仓库不使用第三方分析服务。

欢呼音效：dr_skitz 的 [yay.wav](https://freesound.org/people/dr_skitz/sounds/353923/)，CC0 1.0；本项目进行了剪短和淡出，详见 `assets/cheer-license.txt`。

欢迎入口：进入网页先展示18张精选团队照片轮播，可暂停、手动切换。点击“推门进来”进入庆祝主题，导航“门外相册”返回入口。
